💡 Promise.race：多个任务并行，谁先完成就用谁的结果，其他继续跑但被忽略。
💡 Promise.all：所有任务必须全部完成，才继续下一步（最慢那个决定总耗时）。 
// Promise.race — 任一完成即可继续
await Promise.race([
  buyOnline(8),   // 线上 8s
  buyOffline(6),  // 线下 6s ← 先完成！
]);
// → 实际耗时 ≈ 6s，继续下一步

// Promise.all — 全部完成才继续
await Promise.all([
  和面(4),
  和馅(5),
]);
// → 实际耗时 ≈ 5s（取最慢）
