# JS 可视化教学页

把 JavaScript 知识点做成"可点击运行"的可视化教学页面，让读者通过 before/after 对比直观理解每个方法的效果。

## 页面结构

1. **顶部 Header**：标题 + 副标题 + 作者徽章（姓名/学号，从项目约定读取，默认 `邓嘉毅 · 24001010907`）。
2. **分类筛选栏**：按方法类别分组（增删 / 遍历 / 转换 / 排序等），点击切换显示。
3. **卡片网格**：每个知识点一张卡片。
4. 卡片内容：
   - 方法名（等宽字体，主题色）
   - 一句话中文说明
   - `before` 数组（彩色方块渲染）
   - `after` / `output` 结果区
   - 文字返回值说明
   - `▶ 运行` 按钮（点击执行真实 JS 代码并重绘方块）

## 视觉规范

- 深色背景 `#0f172a`，卡片 `#1e293b`，边框 `#334155`
- 主题色 `#38bdf8`（青蓝）+ `#a78bfa`（紫）渐变标题
- 数组元素用圆角方块，高亮态用主题色背景
- 卡片 hover 上浮 + 边框变主题色
- 响应式网格 `repeat(auto-fill, minmax(340px, 1fr))`

## 实现要点

- 单文件 HTML，内嵌 `<style>` 和 `<script>`，无外部依赖。
- 用一个 `methods` 数组统一管理所有方法，每项含 `name`/`desc`/`fn`。
- `fn` 返回 `{ before, after, out }`，渲染函数把数组转成 `<span class="elem">`。
- 用事件委托绑定"运行"按钮，避免重复注册。
- 分类筛选通过 `data-cat` 属性切换 `.hidden`。

## 交付流程

1. 在 `e:\高级网页设计` 下创建 `<序号>-<主题>.html`（如 `16-1.html`）。
2. 用 Edge 浏览器打开预览：`Start-Process msedge.exe file:///...`。
3. `git add -A` → commit → push 到 GitHub。
