setTimeout — 一次性延时 · setInterval — 周期性重复

邓嘉毅 · 24001010907

① setTimeout — 火箭倒计时

延时指定毫秒后执行一次回调，用 clearTimeout 取消。

const t = setTimeout(() => {
  console.log("发射！");
}, 3000);

// 取消
clearTimeout(t);

点击开始

② setInterval — 秒表

每隔指定毫秒重复执行，用 clearInterval 停止。

const t = setInterval(() => {
  tick();
}, 1000);

// 停止
clearInterval(t);

00:00.000
