一、什么是 JSON

JSON（JavaScript Object Notation）

一种轻量级数据交换格式，使用 "键": 值 的方式描述数据。
可被几乎所有编程语言解析，是 Web 前后端通信的标准格式。

一个完整的 JSON 对象示例

{
  "name": "邓嘉毅",
  "age": 18,
  "student": true,
  "hobbies": ["编程", "音乐", "篮球"],
  "address": {
    "city": "北京",
    "zip": "100000"
  },
  "score": null
}
二、JSON 支持的数据类型
类型说明示例
字符串 string必须用双引号包裹"hello"
数字 number整数、小数、科学计数42 3.14
布尔 boolean只有 true / falsetrue
空值 null表示无值null
对象 object{} 包裹的键值对{ "a": 1 }
数组 array[] 包裹的有序列表[1, 2, 3]

⚠ JSON 不支持：函数、undefined、Date 对象、注释（这是常见误区）。

三、JSON.parse() — 字符串 → 对象

将 JSON 字符串解析为 JavaScript 对象

const jsonStr = '{"name":"Tom","age":20}';
const obj = JSON.parse(jsonStr);

console.log(obj.name); // "Tom"
console.log(obj.age);  // 20
四、JSON.stringify() — 对象 → 字符串

将 JavaScript 对象序列化为 JSON 字符串

const obj = { name: "Tom", age: 20 };
const s = JSON.stringify(obj);

console.log(s); // '{"name":"Tom","age":20}'

// 带缩进，方便阅读
const pretty = JSON.stringify(obj, null, 2);
